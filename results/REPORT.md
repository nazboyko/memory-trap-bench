# MemoryTrap Bench: results

Generated by `uv run python -m memtrap.analyze` from `cases/truth.json` and the run files under `results/kaggle/`. Sizes are binary (1 MB = 1,048,576 bytes). Every model reply is parsed and scored again from its raw text.

## 1. What the harness measured

Three readings per runtime version on GitHub Actions (linux/amd64), median. PHP readings are `memory_get_usage()` deltas with opcache off; Go readings are `runtime.MemStats` deltas after `runtime.GC()` (HeapInuse for maps, StackInuse for goroutines, TotalAlloc for G4). Full values per version are in `cases/truth.json`. The decision quantities are the ratios each case's rules in `cases/cases.json` use (for example r = b / a).
